## Overview
An interactive To-Do List application built using vanilla JavaScript and DOM manipulation. This project covers selecting elements, handling events, and dynamically updating page content.

---

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

---

## Features
- ✅ Add new tasks
- ✅ Toggle tasks as complete/incomplete
- ✅ Delete individual tasks
- ✅ Filter tasks (All / Active / Completed)
- ✅ Live item counter
- ✅ Clear all completed tasks
- ✅ Event delegation for dynamic elements
- ✅ Form validation (no empty tasks)
